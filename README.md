# LaMiaLista
La Mia Lista è un progetto in grado di memorizzare una lista della spesa, cosa fare, posti...
Ci sono molti vantaggi di LaMiaLista, sono:

# Salvataggio della lista
![alt text](https://www.bitdefender.it/media/uploads/2017/07/internet-cookies.jpeg)
Grazie ai cookies, i dati inseriti nel sito verranno salvati nel tuo computer/telefono/tablet, così che prossima volta che visiti il sito troverai la lista pronta.

# Nessuna registrazione per l'utilizzo
![alt text](https://www.web2e.it/images/icone-soluzioniweb/form-registrazione.jpg)
Puoi usare la lista immediatamente, senza che devi inserire dati personali...

# Facile da usare
![alt text](![image](https://github.com/user-attachments/assets/92f6fe5c-c04c-4db4-808f-8f663727d948)
Non servono istruzioni per usarla perchè è semplice e intuitiva.
